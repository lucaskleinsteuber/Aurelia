# Privacy Policy

Aurelia is a media server you run yourself, with apps for Mac, iPhone, iPad, Apple TV, Linux and
the browser. This policy covers the server and all of these apps.

## The short version

The developer of Aurelia collects nothing. Aurelia has no accounts with the developer, no
analytics, no advertising, no tracking and no crash reporting. Everything Aurelia knows stays on
the server that you, or the person who invited you, run, and on your own devices.

## What stays on the server

The server stores what it needs to run your library: the profiles and their names, pictures and
PINs (only as salted hashes), the devices that are signed in, what each profile watched and how
far, favorites, watchlists, collections and settings, and the details and pictures of your titles.
Your media files are only read, never changed or uploaded anywhere. The person who runs the
server can see and delete this data; ask them if you want your profile removed.

## What stays on your device

Each app remembers the servers it connects to, its settings, a cache of pictures and, if you
download titles to watch offline, those downloads and the information shown about them. Sign-in
keys are kept in the system's protected storage (the Keychain on Apple devices). Deleting the app
or signing out removes them.

## When Aurelia connects to other services

- **Your server.** The apps talk only to the Aurelia server you connect them to, usually on your
  local network. Apple devices ask for permission to use the local network for this.
- **TMDB.** Only if the server's owner turns it on, the server sends the titles and years of
  your movies and series to The Movie Database (TMDB) to find their details, cast and pictures.
  This product uses the TMDB API but is not endorsed or certified by TMDB. TMDB's own privacy
  policy applies: https://www.themoviedb.org/privacy-policy
- **OpenSubtitles.** Only if the server's owner sets it up, the server searches OpenSubtitles for
  subtitles of a title and downloads them. OpenSubtitles' privacy policy applies:
  https://www.opensubtitles.com/en/privacy
- **Updates.** The Mac app, the Linux app and the Linux server look for new versions on GitHub
  without signing in. GitHub sees the request like any web visit. You can turn automatic checks
  off in Settings.

None of these services receive your watch history, your profiles or your media files.

## Children

Aurelia does not knowingly collect anything from anyone, including children. Age limits for
profiles are set by the server's owner and are kept on that server.

## Changes and contact
