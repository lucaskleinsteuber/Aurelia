Tarven

Your own movies and TV shows, in a library that feels like a streaming service, on your own hardware.

A free media server for a Mac, a Linux PC or a NAS, with apps for Mac, Linux, Apple TV, iPhone and iPad and a player in any browser. No account, no cloud and no subscription.

Installing the Linux app

Tarven Server for Linux

For a PC without a screen: an old laptop, a mini PC or a Raspberry Pi class computer with systemd.

Install it with one line. The installer picks x64 or arm64 by itself:

curl -fsSL https://raw.githubusercontent.com/lucaskleinsteuber/Tarven/main/packaging/linux/get-tarven.sh | sudo bash

How to start

  1. Pick the computer that keeps the library

    A Mac or Linux PC that is on when you watch, with your media drives attached.

  2. Set it up

    In the Mac or Linux app, choose Set Up This Mac or Set Up This PC. On a Linux server, open the address the installer shows and type its one-time code.

  3. Connect your other devices

    On the server computer, choose Settings › Profiles and Devices › Create Code, or run tarven pair on a Linux server. Type the 8-digit code on the new device.

  4. Choose your profile and watch

    Your files are only ever read: never moved, renamed or converted.

The full getting started guide also explains how to name your folders so everything is recognized.
