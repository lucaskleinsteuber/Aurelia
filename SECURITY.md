# Security policy

Please reproduce a suspected vulnerability on the latest release of the affected
Aurelia product if you can do so safely. See [GitHub Releases](https://github.com/lucaskleinsteuber/Aurelia/releases)
for published builds.

Report vulnerabilities through [GitHub Security Advisories](https://github.com/lucaskleinsteuber/Aurelia/security/advisories/new)
when private reporting is available. Otherwise, use a private contact method listed
by the [repository maintainer](https://github.com/lucaskleinsteuber). You may ask
for a private reporting channel in an issue without describing the vulnerability.

Include the affected product, version and platform, the impact you observed, and
reproduction steps using synthetic data. Remove tokens, passwords, media paths,
and personal information from attachments. Keep exploit details private while the
maintainer investigates and coordinates a fix.
